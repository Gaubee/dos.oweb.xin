# LQIP 术语

| 术语 | 含义 |
| --- | --- |
| LQIP | Low Quality Image Placeholder，图片加载前的低质量占位。 |
| 基色 | CSS `oklab()` 底色，由 `ll`、`aaa`、`bbb` 三个字段表示。 |
| 代表色 | 同时考虑覆盖面积和色度后选出的基色来源。 |
| 色度 | Oklab `a`、`b` 平面的距离；只表示颜色强度，不代表视觉主色。 |
| 灰度网格 | `ca` 到 `cf` 的 3×2 相对 Oklab 亮度布局。 |
| 最小亮度跨度 | 对低对比图片的量化下限，避免 min/max 将微小噪声拉满。 |
| 有符号偏移 | Go 输出 `packed - 2^19`，CSS 先加回 `2^19` 再解包。 |
